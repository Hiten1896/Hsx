# Research notes

## 2026-11-07

- **Groq local tool calling:** [Groq Local Tool Calling](https://console.groq.com/docs/tool-use/local-tool-calling). The application must send JSON tool schemas, execute returned calls itself, and feed results back into the model loop. This matches Hsx's current adapter and orchestrator; the user report about web search is therefore a prompt/routing problem, not a missing provider schema path.
- **Gemini image understanding:** [Gemini image understanding](https://ai.google.dev/gemini-api/docs/generate-content/image-understanding). Inline image bytes are supported for smaller requests; Hsx will cap and resize local images before sending and only do so after an explicit image request.
- **Gemini document processing:** [Gemini document processing](https://ai.google.dev/gemini-api/docs/document-processing). PDF support uses multimodal document input; Hsx's initial file conversion and summaries will prefer local installed libraries and avoid adding LibreOffice.
- **Python Playwright:** [Playwright Python docs](https://playwright.dev/python/docs/intro). The project browser tests use the synchronous Python API and Chromium. Playwright was missing initially and was installed in the project virtual environment for these tests.
- **SQLite:** [Python sqlite3 docs](https://docs.python.org/3/library/sqlite3.html). SQLite is already available in the standard library and is suitable for the incremental local semantic index and restart-safe scheduler state.
- **yt-dlp:** [yt-dlp Python API and postprocessor docs](https://github.com/yt-dlp/yt-dlp#embedding-yt-dlp). Use `YoutubeDL` with explicit format selection, duration checks, and FFmpeg postprocessors; do not execute the standalone updater from Hsx.
- **Browser audio:** [HTML audio element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/audio) and [audio/video delivery](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Audio_and_video_delivery). The built-in `<audio controls>` element provides browser-native playback, seeking and volume controls; mobile playback still requires a user gesture.
- **HTTP Range:** [MDN Range requests](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests). A single byte range response uses `206`, `Content-Range`, and `Accept-Ranges: bytes`; invalid ranges use `416`.
- **Gemini image input:** [Gemini image understanding](https://ai.google.dev/gemini-api/docs/generate-content/image-understanding). Small image inputs are sent as inline bytes. Hsx resizes named/attached images locally before the existing provider adapter sends them.
- **Gemini manual history and thought signatures:** [Gemini function calling](https://ai.google.dev/gemini-api/docs/function-calling), [Gemini thinking](https://ai.google.dev/gemini-api/docs/thinking), and [GenerateContent REST reference](https://ai.google.dev/api/generate-content), reviewed 2026-11-07. The REST API reports a missing thought signature as an error; preserve each returned signature on its original part and preserve call/response IDs. Legacy locally stored calls use the compatibility placeholder required by the task, only when no signature was recorded.
- **Groq model catalog and local tools:** [Models](https://console.groq.com/docs/models), [tool-use overview](https://console.groq.com/docs/tool-use/overview), and [API reference](https://console.groq.com/docs/api-reference), reviewed 2026-11-07. Query the authenticated live models endpoint, ignore inactive/non-chat entries, and use Groq's documented OpenAI-compatible local-tool request/response format; Groq documents local tool use for hosted models.
- **Pillow activity thumbnails:** [Pillow Image module](https://pillow.readthedocs.io/en/stable/reference/Image.html), reviewed 2026-11-07. `Image.open()` loads an image for decoding and `Image.thumbnail((256, 256))` constrains the preview in place; only jailed, size-capped files are opened and the generated JPEG is cached in memory.
- **Rich activity output:** [Console](https://rich.readthedocs.io/en/stable/console.html), [Live display](https://rich.readthedocs.io/en/stable/live.html), and [Syntax](https://rich.readthedocs.io/en/stable/syntax.html), reviewed 2026-11-07. Console detects terminal color support, `NO_COLOR` disables color, `Live` supports updating a spinner/table while a task runs, and `Syntax(..., line_numbers=True)` supports numbered diffs.

No third-party SDK is added by this task. Provider requests continue through Hsx's existing HTTP adapters.
